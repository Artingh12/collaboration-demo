\# Collaboration Demo Project



This project is used to practice Git and GitHub collaboration workflows.



\## Project Description



This project demonstrates a simple open-source collaboration workflow using GitHub Issues, branches, pull requests, code reviews, and CI.



\## How to contribute



1\. Open an issue describing the proposed change.

2\. Create a branch for the issue.

3\. Make the required changes.

4\. Commit and push the changes.

5\. Submit a pull request.

6\. Address code review feedback.
